# RCIM Website Constitution

## Principles

1. Account for every public legacy page, post, and download. Keep private WordPress records out of the site and GitHub.
2. Keep college content in simple static HTML. Staff submit structured facts and approved media; the site owner reviews changes. Use PHP/MariaDB only for new news.
3. Make initial content readable without JavaScript. Use semantic HTML, keyboard access, visible focus, Thai metadata, responsive layout, and optimized media.
4. Retain original URLs where possible, preserve dates, and provide unique titles, canonical URLs, and a sitemap.
5. Keep backups, secrets, and media outside GitHub. Use prepared SQL, password hashing, CSRF protection, and file validation in the news editor.

## Release gates

- A manifest accounts for 73 pages and 185 posts.
- Link and media audits identify gaps before launch.
- The news editor is tested on staging.
- RCIM staff review personnel facts and photos before the domain switch.
